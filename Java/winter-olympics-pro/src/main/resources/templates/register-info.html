Register

Self-registration uses the JSON API.

1. Register

POST /api/v1/auth/register

{
  "username": "your-name",
  "password": "your-password",
  "athlete": {
    "firstName": "Eva",
    "lastName": "Petrova",
    "country": "Bulgaria",
    "gender": "FEMALE",
    "dateOfBirth": "2002-05-01"
  }
}

2. Authenticate

POST /api/v1/auth/login returns a JWT. Send it as Authorization: Bearer <token>.
